# 索尼创意外观模拟器 · RAW 预览（项目上下文）

> 一个纯前端的 Web 工具：上传 RAW 或图片并预览，模拟索尼相机机内的「创意外观 / 创意风格」及参数调节，支持白平衡、分屏对比、摄像头实时预览和导出 JPEG。

## 2. 功能清单

### 2.1 文件读取
- 支持格式：ARW / SRF / SR2（索尼）、CR2 / CR3、NEF / NRW、DNG、RAF、ORF、RW2、PEF、SRW、3FR、IIQ 等，以及 JPEG / PNG / WebP。
- 拖拽或按钮打开；所有处理都在本地浏览器完成，不上传。
- 读取 EXIF：机身、镜头、快门、光圈、ISO、焦距、拍摄时间、方向。
- 内置「色卡示例」：程序生成的 ColorChecker 24 色块、色相×明度场、灰阶、细线（用于看锐度）。

### 2.2 创意外观（Creative Look）

| 代码 | 名称 | 代码 | 名称 |
| --- | --- | --- | --- |
| ST | 标准 | FL2 | 胶片 2 |
| PT | 人像 | FL3 | 胶片 3 |
| NT | 中性 | IN | 即时 |
| VV | 鲜艳 | SH | 柔和高调 |
| VV2 | 鲜艳 2 | BW | 黑白 |
| FL | 胶片 | SE | 深褐色 |

参数（与机内一致）：

| 参数 | 范围 | 默认 |
| --- | --- | --- |
| 对比度 | −9 ~ +9 | 0 |
| 高光 | −9 ~ +9 | 0 |
| 阴影 | −9 ~ +9 | 0 |
| 褪色 | 0 ~ 9 | 0 |
| 饱和度 | −9 ~ +9（BW/SE 禁用） | 0 |
| 锐度 | −9 ~ +9 | 0 |
| 锐度范围 | 1 ~ 5 | 3 |
| 清晰度 | −9 ~ +9 | 0 |

每种外观的参数单独保存，可「重置此外观」。

### 2.3 创意风格（Creative Style，旧机型）
标准、生动、中性、清澈、深色、轻淡、人像、风景、黄昏、夜景、红叶、黑白、棕褐色。
参数：对比度 / 饱和度 / 锐度，范围 ±3。

### 2.4 曝光
- 曝光补偿 −3 ~ +3 EV，1/3 EV 步进。

### 2.5 白平衡（全局，对所有外观生效）
- 模式：拍摄时（默认，不改动）、自动 AWB、日光 5500K、阴影 7500K、阴天 6500K、白炽灯 3200K、荧光灯 暖白 3000K / 冷白 4000K / 昼白 5000K / 日光 6500K（附带品红补偿）、闪光灯 5800K、色温 2500–9900K（100K 步进）。
- AWB 优先级：标准 / 环境优先 / 白色优先（校正强度分别为 0.75 / 0.45 / 0.95）。
- A-B / G-M 偏移：−7 ~ +7，**步进 0.5**；29×29 网格点击/拖动、方向键调整、双击归零。
- 当前 A-B/G-M 偏移为所有白平衡模式共用一组（索尼机内是每个模式各记一组，可按需改）。

### 2.6 查看与对比
- 滚轮 / 双指缩放、拖动平移、双击在「适合」与 100% 间切换。
- RGB 直方图、左上角标签显示外观与白平衡（如 `FL 胶片 | WB 5600K A2.5 M0.5`）。
- 分屏对比，分割线可拖动；「⇄ 调换」切换原图/效果左右位置（快捷键 `S`，状态会记住）。
- 按住看原图（快捷键 `\`）。
- ←/→ 切换外观；外观缩略图实时渲染。

### 2.7 摄像头实时预览
- 顶栏「摄像头」按钮；优先后置，最高 1080p。
- 每帧实时套用全部调色参数；直方图 150ms、缩略图 600ms、AWB（自动模式）1s 刷新一次。
- 镜像（前置默认开启）、切换镜头（多摄像头时显示）。
- 「拍照导出」输出当前帧；「停止」后定格最后一帧继续调参。
- 打开文件、载入色卡或页面切到后台时自动关闭摄像头。

### 2.8 导出
- 按原分辨率分块（2048×2048 tile）GPU 渲染后导出 JPEG（质量 0.95）。
- iOS 限制画布约 1600 万像素，超出时自动缩小。
- 通过 artifact 的 `downloads` 能力保存；非 artifact 环境回退到 `<a download>`。

## 3. 技术实现

### 3.1 RAW 解析（纯 JS）
1. 解析 TIFF 结构（IFD0 / IFD 链 / SubIFD / Exif IFD），读取元数据和 `JPEGInterchangeFormat`、压缩类型为 6/7 的 Strip 作为候选。
2. 若候选不足（< 400 万像素），在整个文件中扫描 `FF D8 FF`，逐段遍历 JPEG 标记，跳过熵编码数据找到 `FF D9`。
3. 只接受浏览器可解码的 SOF0/SOF1/SOF2（排除 DNG/CR2 中的无损 SOF3 原始数据），取像素数最大的一张。
4. 若嵌入 JPEG 自带 EXIF，用于补全元数据与方向；方向在着色器中通过 3×3 UV 变换矩阵处理（支持 1–8 全部方向）。

实测：A7M3 的 ARW（25.6 MB）解析约 17 ms，元数据完整，但该机型嵌入预览仅 1616×1080。

### 3.2 GPU 调色管线（WebGL2 单个片元着色器）

```
源图 (sRGB)
 → 锐化 USM（3×3 邻域，半径由锐度范围决定）
 → 清晰度（基于 mipmap 的局部对比，按中间调加权）
 → 线性化 → 曝光 (×2^EV) → 白平衡增益 (vec3 uWB，按亮度归一化)
 → 高光柔性压缩 (shoulder)
 → 回到 sRGB → 高光 / 阴影（钟形亮度蒙版）
 → S 形对比曲线 x^a / (x^a + (1−x)^a)
 → 六色相分区（红黄绿青蓝品）饱和度倍率 + 色相偏移
 → 全局饱和度 / 自然饱和度
 → 分离色调（暗部 / 亮部着色）
 → 褪色（抬黑）
 → 单色映射（BW / SE 染色）
```

- 每种外观就是一组参数：`c, hi, sh, fade, sat, vib, temp, tint, ev, sharp, clar, shT, hiT, bs[6], bh[6], mono, monoW, monoTone`。
- 视图变换（缩放/平移/分屏/调换）在着色器内完成，同一套代码用于屏幕、缩略图、直方图、导出。

### 3.3 白平衡模型
- 色温 → 普朗克轨迹白点 xy（Kim 等人的三次拟合）→ XYZ → 线性 sRGB。
- 假定「拍摄时 ≈ 5500K」为基准，增益 = `rgb(5500K) / rgb(目标K)`。验证：选 3200K 时增益约 `0.61 : 1 : 2.36`（偏蓝），7500K 时约 `1.20 : 1 : 0.75`（偏暖）。
- A-B：每 1 单位 10 mired（琥珀 = 等效相机色温升高 = 画面变暖）；G-M：每 1 单位 2% 绿色增益。
- AWB：在 160px 缩略图上对接近中性的像素做加权灰度世界估算，按优先级取幂次混合。

### 3.4 FL2 / FL3 调校依据
- **FL2**：官方描述为略微提高对比度、压低色彩、怀旧感；实测偏冷品红，红→品红、蓝→紫、绿→青、黄→粉。
- **FL3**：官方描述为温和压低对比度、色彩清晰、轻盈；实测红→橙、蓝→青，绿/黄降饱和，青橙风格。
- 背景：随 FX2、RX1R III、a7V 发布，之后 A1 II、A9 III 通过固件获得。

### 3.5 持久化
- `localStorage`（带 try/catch）：模式、各外观参数、曝光、白平衡设置、对比调换状态。

## 4. 已知限制

1. **不是真正的 RAW 解码**：使用相机嵌入的 JPEG 预览（已按拍摄时白平衡与标准风格渲染），分辨率取决于机型。
2. **外观为近似模拟**：参数依据官方描述与样张观感调校，索尼未公开原厂 LUT。
3. **白平衡为相对模拟**：无法从 EXIF 获得拍摄时实际色温，预设与色温以 5500K 为基准换算。
4. **摄像头**：画面经过浏览器与系统处理，非 RAW；在嵌入环境中可能因权限策略被阻止，未在真机上测试。

## 5. 后续可选方向

- **真正的 RAW 解码**
  - 方案 A：LibRaw 编译为 WASM，全品牌支持，体积数 MB，需内联。
  - 方案 B：自写索尼 ARW 解码（12bit 压缩解压 + 去马赛克 + 相机色彩矩阵），体积小但仅支持索尼。
- A-B/G-M 偏移改为按白平衡模式分别记录（与机内一致）。
